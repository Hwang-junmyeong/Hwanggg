이전

  • 서버대장·자산대장·접속정보가 엑셀 여러 벌로 나뉘어 서로 내용이 다름
  • 사무실 IP는 엑셀로 관리, 직원이 임의로 IP를 바꿔 충돌 발생
  • VM·방화벽·계정 신청은 메신저와 구두로 접수, 처리 이력 없음
  • SSL VPN은 방화벽 관리자 계정 하나로 공유
  • 랙 위치와 모니터링 상태를 따로 찾아봐야 함
→

인프라 포털

  • 실측 기반 단일 장부: 물리 서버 39대, VM IP 103개, 사무실 IP 205개
  • 직원이 포털에서 IP를 받으면 빈 IP 자동 배정, 설정 파일까지 제공
  • 신청서 4종 전산화, 접수번호·상태·메일·만료 관리
  • VM 신청 → IP 예약 → 완료 시 IDC 맵 자동 반영
  • 배치도·랙·Zabbix 상태를 한 화면에서 확인

편하게 만들되, 기록과 권한은 더 엄격하게 관리합니다.

👥
LDAP 그룹 기반 권한

통합계정 그룹으로 사용자·관리자를 나누고, 퇴사(resigner)·만료 계정은 로그인 단계에서 차단합니다.

🔒
잠금과 로그인 기록

5회 실패 시 15분 잠금. 모든 로그인 시도를 월별 로그로 보관해 추적할 수 있습니다.

🗝️
접속 정보 암호화 보관

VM 접속 정보는 암호화해 저장하고, 허용된 그룹이 비밀번호를 한 번 더 입력해야 열람됩니다. 열람 기록도 남습니다.

📜
관리자 작업 로그

상태 변경, 삭제, 장부 수정, 메일 발송을 모두 기록합니다. 삭제한 신청서도 원본이 로그에 남습니다.

🧹
퇴사자 자동 정리

LDAP 퇴사자 그룹을 기준으로 사무실 IP 장부와 배치도를 자동으로 정리해 남는 권한을 없앱니다.

🔍
초기 비밀번호 점검

처음 비밀번호를 그대로 쓰는 계정을 찾는 점검 도구를 만들고, 첫 로그인 시 비밀번호 변경을 강제합니다.
